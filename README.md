# 🌐 Personal Portfolio Website

A modern and responsive **personal portfolio website** built using **React.js** to showcase my skills, projects, GitHub profile, and contact information. The website features a clean UI, smooth navigation, animations, and a professional design.

---

## 🚀 Live Demo

🔗 **Portfolio:** https://portfolio-coral-seven-57.vercel.app/

---

## 📌 Features

- 🏠 Beautiful Home/About section
- 👩‍💻 Skills showcase
- 📂 Projects section
- 📊 GitHub profile integration
- 📞 Contact page with social links
- 🎨 Modern gradient theme
- 📱 Fully responsive design
- ⚡ Smooth animations and transitions
- 🔄 React Router based navigation
